# Gym logo assets

Add real gym chain logos here as PNG files. Naming convention:

| Chain | Asset filename |
|-------|-----------------|
| SATS | `logo_sats.png` |
| PureGym | `logo_puregym.png` |
| Fitness World | `logo_fitness_world.png` |
| FitnessX | `logo_fitnessx.png` |
| LOOP Fitness | `logo_loop_fitness.png` |
| Arca / Arcaplanet | `logo_arca.png` |
| Evo Fitness | `logo_evo_fitness.png` |
| Anytime Fitness | `logo_anytime_fitness.png` |
| Sporting Health Club | `logo_sporting_health_club.png` |
| Repeat | `logo_repeat.png` |

**Usage:** Uncomment the corresponding `require()` in `src/services/gymLogoService.ts` when you add each file.

**Recommended size:** 128×128 or 256×256 PNG with transparent background.
